# Change Documentation

This repository keeps implementation notes in `docs/changes/`.

## Rule

Every code change must add or update a document in `docs/changes/`.

## File Name

Use:

`YYYY-MM-DD-short-topic.md`

Example:

`2026-03-23-route-wallet-refactor.md`

## Required Sections

Each change document should include:

1. Background
2. What Changed
3. Impact
4. Verification
5. Follow-up / Known Limitations

## Scope

The document should describe:

* Why the change was made
* Which files or modules were affected
* What behavior changed for users or developers
* How the change was verified
